# 幸村精修：造型與遊戲驗證

> 文件狀態（2026-10-14）：目前遊戲停在 v22；本頁的早期版本圖例／數據保留作比較。目前採用範圍以 [狀態與交接](STATUS.md) 為準；參閱 [完整索引](INDEX.md)。

## 目標與基線

以 `art/yukimura-model-guide.png` 為插畫方向，配合後續武士甲冑實物與持武器姿態參考。遊戲已採用 v22：幸村 87,087 三角形、92 骨架及 5 個材質，包含真人頭部、連續腕部、v21 面具和 v22 握姿。仍未達到設定插畫品質；目前依使用者指示暫停，以下精修條件留作後續交接。

## 實作順序與完成條件

1. **幸村高精度造型**：先核對七至八頭身的人體、胸腰輪廓、腿部體積與備戰重心，再製作面甲、兜、鹿角、弧形肩甲、長草摺、袴褲及破披風。避免靠增加零件數或細分現有方塊來宣稱精修完成。
2. **同條件對照**：保存前／側／背、頭肩近景、全身備戰姿態。使用固定相機與中性光，對照 2D 參考的比例、甲片厚度、布料垂墜與輪廓；不要用濾鏡或深陰影掩蓋造型缺陷。
3. **遊戲網格與 UV**：依完成的高精度形體建立可變形網格，保留肩、肘、髖、膝與披風動作需要的拓樸。早期曾評估 25k–40k 三角形；目前幸村約 87k，後續應依真機量測決定重拓樸與 LOD 預算，不能視面數為效能保證。
4. **烘焙與材質**：從高精度模型烘焙 tangent-space normal、AO 等細節；顏色貼圖需要有設計的漆甲色差、磨損位置、布料紋理和舊金邊飾。程序雜訊只作輔助。
5. **骨架和戰鬥**：調整持槍、重心轉移、跑動、揮槍、受擊與披風權重。逐格檢查手掌握槍、甲片穿插和關節連接；不能只確認 animation clip 存在。
6. **遊戲替換與手機最佳化**：先檢查主角在實戰鏡頭中是否仍保有材質／剪影，再建立 LOD、壓縮貼圖與量測真機幀率。大量敵兵使用独立的較低預算，不要求所有角色都套主角精度。

## 算力與成本

本機 Blender 能完成形體編輯、UV、骨架及低成本預覽。Modal 只在高精度烘焙或其他實際耗時工作需要時使用，先跑單一角色、限制工作時間和資源；同一份粗糙幾何配方放到 Modal 不會提高美術品質。若評估 image-to-3D 模型，須另行確認授權、推論資源、背面品質、拓樸與可綁骨架程度，不能直接將生成結果當成遊戲完成品。

## v8 製作紀錄與當時比較圖

v8 延續 v6／v7 專用造型與動作精修：重建收腰胸甲、有厚度的五層肩甲與七組草摺、面甲及護喉、兜與連續鹿角、方孔六文錢、袴褲和垂墜披風；改成 18 骨、八組動作及雙手握槍。主角使用 44,130 三角形，每模型仍一個 primitive、一個材質，敵兵維持原面數。

實際 GLB 的 [正面](art/hero-runtime-front.png)、[側面](art/hero-runtime-side.png)、[背面](art/hero-runtime-back.png)、[頭肩近景](art/hero-runtime-detail.png)、[揮槍](art/hero-runtime-slash.png) 使用固定預覽光線；另有 [不套墨線／紙色濾鏡的 PBR 近景](art/hero-runtime-pbr.png)，可直接檢查形體。這些都是 Babylon.js 渲染，不是新生成的概念圖。

v8 新增可編輯的程序高模母版、獨立不重疊 UV，以及真正的 Cycles 高模到低模烘焙：基礎色、法線、粗糙度／金屬度與 AO。詳見 [高模流程與預覽](HIGH_POLY.md)。細部刻邊、倒角、面甲起伏與次級布褶在高模上生成，再投射到遊戲網格；主角仍保持原有面數和動畫，小兵不套用高模。

這仍不是雕刻師手工完成的插畫級英雄資產，也沒有完成新的手工重拓樸。外輪廓、解剖、布料張力、磨損分布與專用手繪色彩仍需精修；接著再建立 LOD 並量測實體手機表現。
