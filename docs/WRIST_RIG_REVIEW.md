2026-10-14。使用者指出 trial 的手腕仍不自然。本頁保留當時的檢查與方案；後續 v22 已實作固定握點／掌面／肘部方向、逐指 FK、拇指對握、匯出驗證並接入遊戲。沒有安裝 Rigify，也沒有完成下列所有人體限制與碰撞目標；實際範圍見 [v22 採用紀錄](WRIST_STUDY_V22.md)。

## 已確認的問題

- 檢視 `public/review/technique/ieyasu-trial-thrust-side.png`：前手手指的輪廓仍像垂在刀柄上，握拳包覆感不足。畫面觀察不能代替逐指接觸量測。
- `tools/samurai_rig.py` 的 `wrist_score()` 主要降低前臂與手掌縱軸的夾角。它讓手沿武器軸轉動，並以 85% 權重讓肘部彎曲方向追隨手掌衍生方向；肘部原始方向僅佔 15%。因此小夾角仍可能搭配不自然的掌面、手肘和前臂旋轉。
- 此求解器沒有分別限制腕部屈伸、橈尺偏，以及前臂旋前／旋後，也沒有肩部活動限制或人體／鎧甲碰撞檢查。缺少掌面與拇指方向的姿態目標。
- 已有前臂分段扭轉骨與完整手指骨。`upgrade_commander_rigs.py` 的兩段前臂扭轉比例為 0.22／0.72，但這是變形分配，不是姿勢是否合理的判定。
- 槍與刀仍由同一份 `commander-grip.json` 握形起始，手指沒有依招式個別收放。增加面數或渲染算力無法直接修正上述控制問題。
- 現有 grip 測試可檢查握點偏移、軸向與連續性；不應將「腕折 5.8°」當成自然握姿驗收。

## 已讀的開源參考

官方文件網站本次連線受限；以下內容實際由官方 GitHub 原始碼／文件讀取。未匯入第三方程式或動作素材。

1. [Blender Rigify 手臂控制](https://github.com/blender/blender-addons/blob/main/rigify/rigs/limbs/arm.py)：`make_ik_wrist_pivot` 與獨立手部控制。可用於編輯握柄樞紐，不會自動產生正確武術姿勢。
2. [Rigify 肢體控制](https://github.com/blender/blender-addons/blob/main/rigify/rigs/limbs/limb_rigs.py)：IK/FK 切換、獨立 pole control、兩骨 IK 與伸展控制。重點是讓動畫師明確控制肘部方向，而非僅由手部位置推算。
3. [Rigify 手指控制](https://github.com/blender/blender-addons/blob/main/rigify/rigs/limbs/super_finger.py)：各指 master／FK 控制與可選 IK correction，適合分別調整指節包覆與指尖接觸。
4. [Godot TwoBoneIK3D 開發分支文件](https://github.com/godotengine/godot/blob/master/doc/classes/TwoBoneIK3D.xml)：明確以 pole target 建立關節平面，並警示 pole 與前向共線可能造成非預期旋轉。這是控制方式的參考，不是要求換引擎，也不代表目前專案或穩定版已使用此 API。

## 建議製作順序

1. **先做無鎧甲的握姿樣本。** 使用者的道場照片作肩—肘—腕與握距參考；電影劇照只作戲劇性動作參考。照片無法唯一決定三維旋轉，須用正面、側面、上方視角共同驗證。
2. **用 Rigify 或等效的可編輯控制骨架，人工排完整上半身姿勢。** 先做幸村持槍、幸村突刺、家康雙手持刀三個姿勢。肩胛／上臂／肘／前臂一起調整，保留肘部餘量；不能把達不到的武器握點強行交給手腕補償。
3. **分開槍與刀的握姿預設。** 每個握點需同時定義位置、掌面、拇指方向。逐指調整指根與指節，檢查包覆、穿透和浮離。槍的滑握另做階段動畫，不把整段動作當固定焊接。
4. **雙手接觸採單向控制關係。** 先排身體與主要動作弧線，再用武器握點／輔助手 IK 修正接觸；不要讓武器追手、手又追武器。刀與槍可使用不同的控制主從及切換時機。
5. **再處理扭轉、皮膚與護腕。** 區分前臂旋轉和腕部彎曲；用角色的中立姿勢校準局部軸。避免以通用 Euler 數值冒充人體限制。確認裸手合理後再檢查護腕厚度、權重與鎧甲遮擋。
6. **烘焙回既有遊戲骨架。** 控制器留在 Blender，GLB 匯出變形骨動畫；檢查重定向後的接觸與姿勢。目標是保留目前 Babylon 遊戲與手機運算方式，不必在手機即時執行完整控制 rig。

驗收先看三視角裸手與完整角色，再看短段連續動畫。量測補充握點誤差、逐指接觸、分軸旋轉與影格間突變；單一前臂／手掌夾角僅作診斷，不能單獨判定成功。
