# 槍路與破陣：戰鬥手感改版

本輪沿用 Babylon.js。它負責場景、模型、骨架與渲染；招式時序、命中、AI 和勝敗規則由遊戲程式實作。美術精修仍另列在 HERO_REFINEMENT.md，本次不把新增特效稱為模型精雕。

## 操作

- **按住 J／手機「烈」**：橫掃 → 反掃 → 突刺 → 大迴旋，持續循環。點按可逐招出手，動作中再按可預約下一招；停頓超過 0.7 秒回到首招。
- **Space／疾**：向面向方向破陣，取消普通攻擊，短暫無敵。每次衝刺對每個敵兵只判定一次，避免傷害依幀率增加。
- **K／無雙**：蓄滿後發動六文赤蓮。先蓄勢，再四次掃擊，最後大範圍震飛。持續期間不接受重複發動。
- **F／陣**：十勇士在後方護衛與前方突擊間切換。
- 右上角可切換音效；記住本機選擇。音訊只在玩家開始或按音效按鈕後啟用，沒有麥克風或外部音訊服務。

## 招式節奏

| 槍路 | 動作時間 | 命中時刻 | 主要差異 |
|---|---:|---:|---|
| 朱槍橫掃 | 0.34 秒 | 0.11 秒 | 正面扇形、輕擊退 |
| 返刃連斬 | 0.38 秒 | 0.13 秒 | 反方向、更寬的槍路 |
| 破陣突刺 | 0.46 秒 | 0.17 秒 | 窄角度長距離、向前踏步 |
| 赤旋烈風 | 0.64 秒 | 0.28 秒 | 全周圍、較強擊飛 |

`src/combat.mjs` 的同一套時序驅動傷害與骨架採樣。命中事件只觸發一次，不在起手瞬間先扣血。命中頓挫約 35–85ms，只在打中時發生；敵兵群的同一次命中共用一次頓挫，不按人數累加。

`tools/samurai_rig.py` 輸出幸村 idle/run/slash/reverse/thrust/spin/dash/hurt 八組動作。Blender 以雙骨 IK 計算雙手握槍與踏步，再烘焙成普通 GLB 骨架關鍵影格；遊戲依招式進度採樣並短暫混合前後姿勢，與暫停、命中頓挫同步。大迴旋持續朝同方向完成一圈，避免先轉身再倒轉。這是程序編排，沒有動作捕捉或執行期地形 IK。

十名隊友、德川足輕與家康共用 18 骨骨架及 idle/run/thrust/hurt/fall 五組動作。Babylon.js 的 BakedVertexAnimationManager 讓 GPU 實例共用動畫資料，每名角色獨立選擇影格與步伐相位；不是十個角色同步抖動。隊友各自尋敵、轉身、起手、命中及收招，破軍陣會主動接敵。普通敵兵刺擊在約 0.30 秒命中，家康重擊維持 0.75 秒預警；受擊／倒地動作跟隨戰鬥狀態。

## 戰場反應

- 活著的敵兵會受擊停頓、滑退或被拋起；倒下後保留短暫飛退／倒地輪廓，再淡出縮小，避免即刻消失。
- 擊退用速度與阻尼更新；陣亡輪廓快速清理，持續保留上限 28 個。
- 敵兵從周圍靠近，初始敵軍更接近玩家；普通攻擊有短前搖，家康重擊有 0.75 秒預警。
- 家康對輕擊退較有抗性，普通斬擊不直接取消其蓄勢；重招可打斷。
- 連擊統計命中人次，擊破另計。命中和擊破都增加無雙，十勇士支援的擊破仍保留。

## 特效與音效預算

`src/combat-fx.ts` 使用共用材質的雙色弧形槍光、突刺光痕、火花與雪屑，不使用手機昂貴的全畫面 bloom。短命特效最多 96 個 mesh（減少動態效果設定為 40 個），到上限回收最早的特效。

`src/battle-audio.ts` 用 Web Audio 合成槍風、碰撞、低鼓與受擊聲，不需要下載音檔。限制同時聲部數及命中發聲頻率。這是動作提示音，尚無配樂、環境音或角色配音。

鏡頭略靠近角色，命中有克制震動／視角推近，無雙加赤紅邊緣和爆發段落。尊重 `prefers-reduced-motion`：關閉震動和無雙鏡頭推近、降低特效數與 UI 動畫。

## 驗證

單元測試檢查前搖、單次命中、連段順序、輸入預約、取消、扇形／突刺方向與不同幀率。瀏覽器測試檢查實際四段切換、衝刺單次傷害、無雙五次脈衝、暫停、殘影清理、音效開關，以及原本的完整勝敗與手機操作。

開發測試可建立固定敵兵陣列以驗證戰鬥，該控制介面不進 production build。手機測試是 Chromium 尺寸與觸控模擬，尚未取得實體手機幀率；不保證所有裝置同等流暢。

模型載入 URL 帶 `rev=high-8`，避免已玩過舊版的瀏覽器沿用只有三組動作的快取 GLB。後續變更必要動畫或模型格式時同步更新這個版本值。
