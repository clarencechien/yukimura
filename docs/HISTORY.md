# 歷史與架空界線

## 暫定歷史背景（待外部來源逐條核對）
- 大坂冬之陣發生於 1614 年；真田信繁（通稱幸村）守衛大坂城南面的真田丸。
- 真田丸以防禦工事、壕溝與柵欄為視覺核心。
- 幸村衝擊德川家康本陣的敘事屬於 1615 年夏之陣；本作把它改編成冬之陣架空突擊。
- 赤備、鹿角兜、六文錢與十文字槍是角色視覺語彙；不主張全部為本戰役裝束的確證復原。
- 雪景是冬季藝術化處理，不主張特定交戰日確實降雪。
