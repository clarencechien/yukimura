## 證據與限制

v22 基線本機與 CI 通過 28 項規則／資產測試、10 項 E2E、7 項 Pages 測試，共 45 項。另有 2,352 個非倒地手部取樣及四段動畫的手指接觸近似檢查。上線後抽查 15 個檔案，HTTP 200 且 SHA-256 與建置相符；不是全站每個檔案的新一輪校驗。

手指檢查使用 19.8 mm 圓柱及受該手指主要權重影響的頂點，允許小於 2 mm 壓入；不是完整三角形碰撞或人體活動範圍證明。沒有安裝 Rigify，借鑑其控制方式後，以既有骨架做離線兩骨 IK／FK。其他招式仍需逐一檢查，不能宣稱所有腕部問題已解決。

目前僅驗證 Chromium 軟體 WebGL、手機尺寸與觸控模擬，沒有實體手機 FPS／熱降頻數據。未完成全角色 LOD、十勇士獨立造型、手工雕刻／重拓樸及插畫等級材質。早期單獨手部研究的 LOD 不代表遊戲主將已有 LOD。離線電影研究是試渲幀，不是已交付的十秒影片。

## 接手與重建

一般開發只需 Node.js 22.12+、`npm ci`、`npm run dev`，不需重新生成模型或提供 Modal 憑證。使用既有 checkout；不需另建 worktree。

若未來要重建 v22，先保存手工修改，安裝 Blender 4.3.x（此環境 CLI 4.3.2）及 Node 依賴，再依序：

```sh
npm run models:trial
npm run models:wrists
npm run models:install-wrists
```

前兩步產生候選，第三步驗證、安裝 GLB 與握姿設定，並重烘焙家康 GPU 動畫資料。`.tmp` 不進 Git，新工作區需要重建其中的候選及報告；不要只複製 GLB 而漏掉 palette。詳見 [模型流程](MODELS.md) 與 [握姿流程](WRIST_STUDY_V22.md)。本次文件整理沒有重跑建模或完整遊戲測試。
