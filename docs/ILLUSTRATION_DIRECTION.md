# 插畫風格：先定 2D，再建模

## 視覺基準

- `art/yukimura-model-guide.png`：本輪 image gen 人物設定圖。前／側／背視圖、備戰姿態、甲片／繫帶／披風細節。這是建模目標，不是現有 GLB 的渲染圖。
- `art/battlefield-keyframe.png`：同一美術方向的 2D 戰場構圖目標。不是遊戲截圖，也不放進戰場冒充 3D。
- `art/models-lineup.png`：本機 Blender 模型的實際渲染。
- `screenshots/battle.png`：實際瀏覽器的遊戲畫面。

設定集不出現在戰鬥 UI；主選單仍僅使用原概念圖左側的戰場裁切。

## 為什麼原模型像玩具

問題首先是輪廓：頭肩偏大、方塊肩甲、短草摺、細直腿、整齊站姿；再加上平均的亮漆材質與規律地景，會像模型桌遊。增加金屬度、鉚釘或渲染品質無法自行修正這個問題。

## 已做的造型校準

1. 拉長腿與軀幹，缩小頭盔／頭部，收窄肩寬，重心略向前。
2. 方塊肩甲改成連續曲面叠片；草摺改成長而外張的九片曲面，向大腿延伸。
3. 袴褲加寬，保留垂墜折片；披風改成不對稱破邊，長槍向前傾。
4. 赤甲降低金屬度、提高粗糙度；頂點色加入色差與下擺髒污，配件使用舊金。
5. 2D 設定圖已封裝到 Blender 源檔的 `REFERENCE` collection；預設隱藏，可在 Outliner 開啟。它不會匯出到遊戲 GLB。

v5 已進一步製作曲面護頸、面甲、鹿角、曲面脛甲、皺褶披風與共用筆觸貼圖，並為幸村建立 14 骨及三組動作。但其程序拼裝造型仍明顯落後設定圖。這主要是造型／材質製作方法的限制，不是因為沒有 Modal，也不是手機只能容納目前的面數。後續應先完成高精度幸村造型，再重拓樸、烘焙和建立 LOD；不能用加面數、加反光或改濾鏡宣稱已完成插畫品質。

## 戰場而非展示台

- 移除圓錐松樹、圓蛋形雪堆、乾淨的矩形道路。
- 以共享紋理呈現泥雪、細碎筆觸和不連續車轍；碎木、車輪、插地槍矛作為近景。
- 不規則破損木柵、撕裂旗幟、枯樹、遠方槍陣形成前中後景。
- 硝煙以共享透明材質與少量 billboard 漂移，避免昂貴的流體模擬。
- 降低鏡頭高度，保留全向敵軍可讀性；畫面使用輕量墨線／紙色明暗處理，UI 不套濾鏡。
- 提高軟體繪圖環境的內部解析度，減少先前 2.4 倍縮放造成的模糊；這有實際效能代價，未作實體手機效能保證。

## 成本與共用

本輪使用 image gen 生成兩張 2D 方向圖；3D 建模仍由本機 Blender CPU 完成，未呼叫 Modal／付費 3D 生成服务。角色共用幾何零件及單材質配置，GLB 維持每角色一個 primitive；v5 改用三張外部共用圖集，取代舊版內嵌表面查表。`manifest.json` 的 API 計數僅指建模腳本，不包含 2D 圖片生成。
