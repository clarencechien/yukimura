側倒・共用護脛與靴子

共用護脛（預設） · 前輪胸肩接續 · 前輪共用肩甲 · 前輪共用頭盔 · 前輪四格換圖 · 原三格版本 · 前輪比例與替換修稿對照

左側保留前輪換姿；右側預設在側倒段沿用同一組護脛與靴子，在大腿後方平移滑出；在離掌後，先讓原肩甲轉落並露出既有頸肩內層，再接側倒；頭盔與肩甲分別獨立轉動，由收腳、落刀與卸力，加入一張既有低頭稿作短暫過渡，再接原三張側倒原畫；1220 ms 後沿用同一片肩甲並用既有襯布補底；共用雙臂，地上的刀保持原位。

獨立試作，尚未替換遊戲。近地起保留原圖膝甲／腰帶，400 ms 不再切換整張下身；修補圖只補護脛與鞋移開後的區域。540 ms 鬆手，刀碰地後轉平；860–1180 ms 接胸肩卸力；預設版 1200–1240 ms 使用低頭過渡格，之後接回原三格；原三格版仍在 1220 ms 後換姿；身體仍有關鍵格換姿與接縫，尚非全身連續動畫。前段原畫換姿及裁邊仍待精修。
