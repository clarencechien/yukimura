# 路線修正：保留插畫的 2.5D 重打光

> 已完成第一輪：以單一插畫、人工淺浮雕與 Blender 光照差異合成三張結果。見 [實際補光對照與驗證](RELIGHT_STUDY.md)。下文的 AI 工具仍只查核文件，尚未推論。

2026-10-15（Asia/Taipei）。使用者澄清：要以參考插畫為實際素材，借助 Blender 增強光影，不要求完整 3D。此前 `BLENDER_STUDY.md` 做的是舊 v22 模型離線渲染，沒有完成「以插畫為素材」的目標。它保留為流程比較，不再作為這條路線的造型基底。

## 採用方向

**原插畫 → 分層／去背 → 材質與表面方向估計 → Blender 平面或淺浮雕 → 固定視角透明幀。**

讓原圖提供輪廓、甲片、面頬、繫繩與布紋；Blender 提供鏡頭、光影合成、少量景深、接地影與特效。首輪不自動生出完整人形 mesh，也不把角色重新做成舊模型外觀。

## 最小驗證方式與進度

已完成素材整理、保色基準、人工粗表面與三種照明。第 3 項的可動分層、第 4 項的 AI 推論及第 7 項的動畫尚未完成。

1. 從已確認的幸村插畫固定一個造型與視角，先取得單人、無字、完整鹿角／長槍／腳部的乾淨素材。多視角設定表不是現成動畫；正式遊戲視角需另確認，不能靠把平面轉 35°就變出俯視頭頂。
2. 原圖完整保留。先做不受燈光影響的色彩基準，確認匯入、alpha 與色彩管理沒有改壞；此基準只作保色比較，不能宣稱它能真正重打光。
3. 手工分出頭盔、身體、雙臂、槍、披風與前後層，處理層間遮擋及補齊小幅移動露出的邊緣；首輪不做大幅肢體動作。
4. 優先評估 Marigold 的 normals／intrinsics；可先用人工遮罩和粗表面方向作低成本對照。深度模型只在需要淺浮雕／小幅視差時加入。
5. 原圖已有畫好的陰影與高光。光影版需以估計的底色／材質為基礎，或採受限的增補光影合成；不能把既有明暗當純 albedo 再強光照一次。法線圖使用資料色彩空間並核對相機座標、通道方向與 Blender 對應。
6. 在同一鏡頭出三種照明：中性、左側火光、右側冷鬼火。並排比較原圖和結果，先確認六文錢、面具、手指與繫繩沒有被改樣，保留度優先於立體感。
7. 通過後再做呼吸、披風、槍身等有限分層動畫；最後輸出透明 PNG／圖集給 2D 引擎。原圖解析度限制有效細節，Blender 輸出 4K 不會自動增加原圖資訊。

## 適用範圍

固定視角、細膩材質、光照變化、待機與有限肢體動作適合這條路線。大幅轉身、背面、跨身揮槍仍需要額外視角／關鍵姿勢、補畫或部分簡模支援。逐幀獨立生成容易讓甲片、手指與臉漂移；不能把單張高品質插畫等同已解決整套戰鬥動畫。

首個驗收標準改為：**同一張插畫，在不同光照下仍看起來是同一位幸村、同一套甲冑。** 在此之前，不擴成多方向動畫、不繼續精修 v22 幾何來代替這個目標。
