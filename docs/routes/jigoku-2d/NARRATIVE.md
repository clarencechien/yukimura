# 真田・六文劫

暫定名稱與原創世界觀，2026-10-15。這是與《赤冬》並行的地獄路線，尚未替換既有遊戲文案。

## 核心文案

**六文不渡，赤槍開路。**

大坂的最後一聲戰鼓，早已沉入夏火。
真田幸村與十勇士奮戰至終，仍未能抵達那個改寫命運的瞬間。

死後，戰鼓卻沒有停。

在修羅戰境之外，他們看見一條沒有盡頭的送葬隊伍。亡者披著破甲，越過焦黑關門；每到天明之前，又被喚回同一場敗仗。

河上有人說：六枚銅錢，可以渡你一人。
幸村望向身後，將錢重新繫上赤甲。

「那便不渡。吾等自己開路。」

十勇士循誓而來，赤旗在灰燼中再起。
穿過燼關、血泥原與刀山古道，斬斷役使亡魂的軍令。
這一次，槍尖所向，不只是一人的本陣。

**是讓所有跟隨他的人，都能走出這場戰爭。**

## 世界規則

- 「劫城」是未竟戰事與亡者執念凝成的原創地獄邊境，不等同佛教完整宇宙地圖。
- 十勇士為後世傳說角色，本作作為誓約化身再現；不聲稱十人曾同列歷史軍籍。
- 六文錢化為六盞魂燈。燈可照亮被困亡者，也會引來循光而至的怨軍；這是遊戲設計。
- 亡魂獲救會留下一段記憶，讓每次周回增加故事；不是把地獄居民一律當成應被殺戮的怪物。
- 家康的「金甲之影」是戰場記憶與主角執念構成的對手。它守住未竟之路，但不代表歷史上的家康被判入地獄。

## 首關：三途・燼關

河水映著燒毀的大坂，灰燼像雪一樣落下。赤備踏上濕石，關門後傳來沒有活人的點兵聲。

目標：救出三隊被鎖在戰陣中的亡魂，重燃橋頭魂燈，突破「焚旗鬼將」，開啟渡往內城的路。

場景節奏：河岸登陸 → 石坪受圍 → 橋頭救援 → 燼關破陣。前景門樓可遮住遠處威脅，但角色靠近時必須淡出，不用遮擋掩蓋打擊判定。

敵人：灰燼足輕、纏旗弓手、負鐘鬼兵；首領焚旗鬼將是本作原創亡軍統領。

## 開場對白

【渡守】六文，只渡一人。你身後那十道影，過不去。

【幸村】生前未能帶他們走完。死後，豈能獨行？

【佐助】主公，前頭都是敵陣。

【幸村】好。總比無路可走。

【才藏】赤旗已立。今夜，讓地獄記住我們。

## 戰鬥短句與介面文字

- 出陣：**踏入劫城**
- 任務：**破燼關，迎亡魂**
- 衝刺・灰渡：「借一步，過生死。」
- 槍技・赤蓮返：「退開！」
- 奧義・六文開路：「此六文，換諸君一條生路！」
- 十勇士・結誓：「一人不退，十人不散。」
- 十勇士・破軍：「赤旗所向，隨我開路！」
- 首領前：「爾等守的是關，還是那場早已結束的戰爭？」

## 勝敗與周回

勝利：**一關已破，尚有未歸之人。**

【旁白】亡魂越過橋頭。遠處，又一座關門亮起赤火。

【幸村】記住他們的名字。下一關，不許再少一人。

敗北：**赤旗暫落，六文未散。**

【佐助】主公，燈還亮著。

【幸村】那便整軍。還有人等我們。

周回候選：落燼 → 業火 → 鬼雨 → 血月 → 無明 → 歸誓。名稱是原創章節語彙，不宣稱佛教六道的逐項對應；每輪增強敵軍組合與地形壓力的玩法尚未實作。
