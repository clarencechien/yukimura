## 這輪能玩什麼

**六文不渡，赤槍開路。**

燼關前，守關的鬼武者仍握著生前的刀。他已忘記效忠誰，卻沒有忘記攔住每一個離去的人。幸村壓低身勢，收槍，踏穩——赤槍落處，讓這場戰爭先放過一個亡魂。

- 按 **開始交鋒**：鬼武者開始主動出刀，雙方各三格血；初始仍為姿勢練習，載入畫面時不會被偷襲。結束交鋒會回到練習並重置。
- 按 **L／格擋**：短暫防禦 580 ms，從按下起 1100 ms 後可再用。格擋中不能出槍，出槍中不能格擋；太早按會在刀到前失效。手機有獨立按鈕。
- 按 **J／空白鍵**，或手機的 **短刺** 按鈕：蓄勢、短刺、收槍。短刺不能重複出手，沒有按住連發。
- 按 **K／橫掃**：低位攻腿；短刺收槍時按鈕亮起為「接橫掃」，此時按 K 可預約一招，收槍完成後自動接續。重複按不增加攻擊次數。
- **對手**：預設燼關鬼武者；亦可切回上一輪怨火封印，短刺可命中封印，低掃碰不到懸空封印。
- **槍尖可及**：短刺槍尖進入上身、低掃槍尖進入近側腿部碰撞圓才扣血；三次命中擊倒鬼武者／破封。
- **一步之外**：目標位於射程外，出槍會刺空。改變間合會重置目標；攻擊途中不能切換。
- **再戰鬼武者／重聚封印**：重置血量、命中次數與攻擊動作；暫停、逐次試槍。
- **命中特效**：切換火星、短槍光軌、封印震動與小幅鏡頭震動；開關不改變傷害規則。70 ms 命中停頓屬於動作時序，保留。
- **音效**預設關閉，可自行開啟；為 Web Audio 合成的簡短出槍／命中聲，不是專業錄製的兵器音效。
- **顯示槍尖判定**：青圈是目標碰撞範圍，白點為槍尖，金點表示有效攻擊幀。此項用於動作檢查。

手機支援觸控；全螢幕依瀏覽器支援，亦可轉橫向。切到背景分頁會暫停，回來後手動繼續。偏好減少動態時，不啟用漂浮落燼與鏡頭震動。

## 攻守規則：可應對的出刀與反擊空隙

鬼武者在交鋒開始後等待 1200 ms，**蓄刀 850 ms → 出刀 180 ms → 收刀 1400 ms**，之後再次蓄刀。預兆包含文字、頭頂進度條與地面間合線；不依賴顏色或鏡頭震動。玩家在出刀起點仍處於格擋期間就能擋下，格擋結束後可趁收刀短刺反擊。近距出刀只扣一格血；「一步之外」會揮空。短刺或低掃命中也會打斷蓄刀，重啟收刀空隙。

## 從動作到命中

待機、短刺、低掃與格擋使用十四個插畫部件，取代舊 Blender 圖集與六張橫掃姿勢；敵人使用十二個共用姿勢、四個低掃受擊／回穩姿勢與三個出刀姿勢。

1. 短刺與低掃以 30 Hz 更新固定長度四肢及腰胯變換；Phaser 負責即時合成圖層、場景、輸入、粒子與 tween。
2. 使用共用槍的實際軸線端點，套用與畫面相同的位移及角度；短刺碰撞資料為 [shared-spear-track.json](combat/shared-spear-track.json)，低掃為 [shared-sweep-track.json](combat/shared-sweep-track.json)。舊 `spear-track.json` 只保留作歷史造型與橫掃交接素材來源。
3. 僅在第 **15–16 幀**有效（零起算 14–15）。使用前後槍尖位置的線段對圓判定，避免低更新頻率越過碰撞位置。每次攻擊最多傷害一次。
4. 命中時角色動畫停頓 70 ms，同時觸發火星與封印震動；收槍完成才開始下一招；短刺收勢期間可預約一次橫掃。
5. 前腳與後腳腳尖沿用固定接觸點，在對應位置加接地陰影；背景是新生成的一張空場景畫，沒有預先畫死的人物。

![槍尖與封印碰撞範圍檢查](combat/hit-check.jpg)

這是固定站位、單目標的戰鬥回饋試作。鬼武者會受擊與倒下，交鋒模式會依固定時序蓄刀攻擊；封印仍可選作測試目標。**沒有移動尋路、方向切換或完整關卡；目前只有短刺接低掃這一組連招**。背景石台不是可碰撞地形；陰影、人物高光與材質不是即時 3D 光照。圖層膝踝接縫與肩胯轉動仍有改善空間。
