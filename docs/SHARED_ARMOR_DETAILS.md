# v16：共用甲冑細節與雙倍腕部

> 歷史／研究文件（2026-10-14 整理）：以下「目前」、測試數據與待辦指原記錄階段，不代表 v22 現況；舊版命令如需精確重現，應使用對應 Git 版本。目前採用範圍以 [狀態與交接](STATUS.md) 為準；參閱 [完整索引](INDEX.md)。

這版延續 v15 體格修正，依要求把兩位主將腕部截面加粗至 v15 的 2 倍，並把細節做成四種角色共用的製作工具。新增的是可見的繫繩、金屬孔圈、細包邊與貼身束帶；沒有宣稱整體已達插畫品質。

## 共用方式

`tools/detail_commanders.py` 的 `Fittings` 提供繩索、環形金屬扣及網格／UV／蒙皮生成。`Surface` 把零件貼合角色已有表面，沿用附近頂點的蒙皮權重。幸村、家康、赤備足輕與德川足輕都使用同一套函式。修改共用函式後重建，即更新四種角色；並非四套獨立手工細節。

- 主將：胸甲、肩甲交叉繫繩，甲緣細包邊，腕部兩圈束帶。兩位主將各 288 個新增構造片段，配件法線與 ORM 貼圖的 SHA-256 完全相同。
- 小兵：使用相同繩索與金屬扣函式的簡化版本，各新增 18 個構造片段、640 三角形。重新映射到原有繩索／金屬圖集，維持單一材質與 18 骨，沒有套用主將 92 骨。
- 遊戲材質：`src/material-finish.ts` 透過每個 Scene 的 WeakMap 共用 forged / woven 兩張 512² 細節紋理，使用 Babylon 原生 PBR detailMap。R 為灰階色彩，G 為法線 Y，B 為粗糙度，A 為法線 X。
- 前述共用包括製作配方、紋理及群兵的 GPU 實例；主將與小兵的最終網格仍各自匯出，因為體型、配色和細節等級不同。沒有宣稱四種角色使用完全相同的最終 GLB 或骨架。

## 腕圍

讀取未修改的 v15 `*-physique.blend`。以每側前臂控制骨為軸，在長度參數 0.93–1.07 的腕部區域，把橫截面向量乘 2，兩端逐漸消退到前臂與掌根；同時處理布革與護腕甲片。新增束帶重新對新表面投射。

輸出紀錄取長度參數 0.96–1.04 內的 117／119 個頂點，測得左右腕半徑倍率皆為 2。這是依此次需求採用的誇張武將比例，並非人體解剖正確性的認證。骨架與動畫保持原綁定；握持座標測試不等於每個手指表面都沒有穿模。

兩位主將各比 v15 增加 13,432 三角形與一個材質部分；群兵維持一個部分。glTF 圖集共 11 張，其中 2 張新配件圖集由主將共用。另有兩張 runtime detailMap 供四種角色共用。材質增加了紋理取樣成本，尚未做真手機效能測量。

本輪 Blender 建模、貼圖生成與匯出使用 CPU。未呼叫 Modal 或付費 API。使用者裝置上的 Babylon 渲染、群兵／家康骨架調色盤使用 GPU；本環境 Chromium 使用 SwiftShader 軟體 GPU，因此不能以測試耗時推論裝置 GPU 效能。

## 重建

`npm run models:details` 從 v15 可編輯主將與 `assets/source/samurai-kit.blend` 的基礎小兵重建，安裝四個 GLB 後重建 GPU 動画調色盤。`models:physique`、`models:rigs` 與完整 `models` 亦已串接此步驟。

輸出可編輯場景位於 `assets/optimized/commanders/*-detail.blend`，暫存 GLB／數據位於 `.tmp/detail-v16/`。重建不以已修改的遊戲模型當來源，不會重複疊加零件或腕圍。

內部啟動 Vite port 5180 後，執行 `node tools/capture-detail.mjs` 與 `python3 tools/detail_gallery.py --publish`。`renders/detail-v16/index.html` 包含 20 張內嵌比較圖，不依賴圖片相對路徑或 JavaScript；`--publish` 同時更新 GitHub Pages 使用的 `public/review/index.html`。

重新匯出小兵時修正來源的逐角色 fps（30 / 90），以及 glTF 匯入 NLA 從 frame 1 起算造成的多一影格。單元測試現檢查每段動畫維持原始秒數，避免製作共用細節意外改變攻擊／倒地節奏。

## 尚未完成

目前是程序建模的構造细節；面甲造型、厚重肩甲懸掛、掌根形態與自然布革摺痕仍需專項雕塑。金屬孔圈是附加的表面幾何，沒有在原胸甲挖出真正貫穿孔。細節紋理屬共用的小尺度凹凸，並未重新雕塑／烘焙全部甲片，更不代表達到插畫精細度。

遊戲與本頁模型比較隨 GitHub Actions 發布。最新比較頁位於網站 `/yukimura/review/`；靜態入口為 `public/review/index.html`，20 張 PNG 已內嵌，可離線開啟。
