# 家康、倒地與風雪戰鬥 v9

> 歷史／研究文件（2026-10-14 整理）：以下「目前」、測試數據與待辦指原記錄階段，不代表 v22 現況；舊版命令如需精確重現，應使用對應 Git 版本。目前採用範圍以 [狀態與交接](STATUS.md) 為準；參閱 [完整索引](INDEX.md)。

## 家康沿用主角精細套件

家康與幸村共用曲面胴甲、肩甲、草摺、手甲、布褶和 18 骨骨架。移除幸村的鹿角、六文錢與十文字槍，加入黑金甲、蕨形前立、三葉葵紋、銀色鬚飾與彎曲刀身。這是遊戲美術設計，不宣稱復原某套歷史甲冑。

家康使用獨立 1024² 高低模烘焙與刀柄握距；一般士兵繼續共用低面數模型／貼圖和 GPU 動畫。家康的場內放大倍率從 1.4 改為 1.13，靠甲冑輪廓與本陣辨識度呈現統帥，而非巨大比例。

## 身體倒地，不再整隻翻倒

兩組骨架動作包含失衡、屈膝、手臂支撐、髖／肩落地與回彈收勢；手腳與兵器各自移動。姿勢在 Blender 離線製作，校正變形後網格的地面接觸高度，再烘焙進 Babylon.js 原生 GPU palette。

移除死亡時 actor root 的橫向旋轉與全身縮小。每名士兵選擇不同姿態及播放速度，擊飛沿用受擊速度，落地增加揚雪與較強滑動阻力。最多保留 28 具短暫殘影，再沉入雪面少許並清理；沒有即時 ragdoll 或與障礙物碰撞的全身物理。

`npm run models:animations` 可從現有 Blender 源檔重新匯出動畫並更新 GPU palette，避免每次調動作都重烘焙貼圖。本輪已實際重建四套動畫並重新驗證；完成的高模在生成過程暫時排除於場景計算，儲存源檔時恢復可編輯狀態。

## 風雪與招式可讀性

- Babylon.js 原生粒子實作斜向雪花和貼地吹雪。桌面池 724、觸控裝置 324，減少動態偏好 126；共用一張程序軟邊貼圖。
- 緩慢陣風、霧色與冬陽強度變化；十面破旗變形飄動，其餘保持合併靜態幾何。暫停時粒子也停止。
- 槍痕分為暗紅外緣、朱紅殘影與細金亮刃；突刺與命中火花保留方向性，雪塵改為軟邊 billboard。
- 無雙先六文聚氣，脈衝掀起地面光環與雪塵，末擊展開六片赤蓮。近身短暫光照加強甲冑反應，不增加全螢幕 bloom。
- 特效上限維持 96 個，減少動態偏好 40 個；傷害時機、範圍及連段規則不因視覺特效更動。

驗收以實際模型近景、倒地連續畫面與引擎錄影為準。程序動畫仍需藝術調整，沒有動作捕捉；手機瀏覽器測試仍不能取代實體手機幀率測量。
