# 真田・赤冬 / Crimson Winter

## 第一個可玩切片
1. 歷史：冬之陣真田丸防衛作為環境；攻至家康本陣為明確標示的架空路線。
2. 2D：朱紅、墨黑、霧藍、舊金與雪白；鹿角兜、六文錢、十文字槍；斜俯視大軍與低多邊形剪影。
3. 3D：Blender 可重建 GLB，角色、足輕與家康；Modal 使用相同建模程式，不將憑證放入前端。
4. 遊戲：Babylon.js + TypeScript + Vite。使用引擎場景、相機、材質、GLB 載入、實例化；自訂遊戲規則。
5. 操作：WASD／方向鍵、J 攻擊、空白衝刺、K 無雙、F 士兵陣形、P 暫停；手機虛擬搖桿與按鈕。
6. 遭遇：四向敵軍、連擊、擊退、士兵援護、進度推進、家康首領、勝敗與重玩。
7. 難度：戰前選擇，通關增加周目與敵方血量／速度／密度；localStorage 保留周目。
8. 驗證：建置、戰鬥規則測試、桌面／手機瀏覽器 smoke test、GLB 載入及無 console error。

## 界線與後續
首版為短局原型，不宣稱完成商業級無雙遊戲。跑酷式持續推進與自由走位並存；保持畫面大量敵兵但限制活動數量。
後續可加入骨架動畫、音效錄製、更多武將與關卡；先驗證打擊感和手機效能。
不複製 Top Lords 或三國無雙的美術與素材。
