# 幸村與家康：連續手部及握持修正

## 模型

兩位武將以 MPFB／MakeHuman CC0 人體基底衍生的連續手套，取代球體手掌及獨立管狀手指。每隻手約 1,572 三角面；手背甲沿離線試作的實際手背曲面擬合。左手由右手鏡射並反轉面繞序，沿用共用建模流程。

保留幸村赤備、鹿角和六文錢，以及家康較寬的黑金肩甲、羊齒前立；家康遊戲中的 1.65 倍尺寸維持原設定。本次主要修正手部與握持，並非重新製作整套甲冑或臉部。

兩人仍各使用單一網格／材質，重新執行高模到低模的色彩、切線法線、粗糙度／金屬及 AO 烘焙。幸村貼圖 2048，家康 1024；各自的漆甲遮罩跟著新 UV 重新生成。

## 動作

遊戲保留 18 根骨骼。22 骨骼的離線手部試作供應固定握姿幾何，沒有額外增加遊戲內手指骨骼或開合動畫。

手掌的握持中心與軸向，現在根據武器姿勢求解。手腕目標送入前臂 IK，因此手臂末端與手掌連接。家康改用居中持刀架勢，左手位於右手下方 15 cm，持刀點移至胸甲前方；刀柄半徑對齊共用握姿，直柄延長至 38.5 cm 以涵蓋下手。直柄延長保留原有 UV 與材質。

前臂方向使用肘部平面建立穩定的旋轉座標，避免最短弧旋轉接近反向時突然扭轉。武將動畫以 90 Hz 離線取樣；原有攻擊、跑步等時長保持不變。家康的 GPU 動畫表仍由既有 60 Hz 流程產生。倒地動畫允許鬆手，不納入保持握持的測試。

## 資產與再現

- `assets/vendor/mpfb/commander-grip.json`：精簡手部網格及貼合手甲；人體資料 CC0，手甲為專案原創。上游授權與來源雜湊同目錄保存。
- `tools/export_commander_hand.py`：由 `assets/cinema/open-hand-study.blend` 產生上述素材；日常模型重建直接使用 JSON，不需重建離線試作。
- `tools/commander_hands.py`：將手型接入既有角色座標系。
- `tools/refine_hero.py`、`tools/samurai_rig.py`：共用模型與握持修正。
- `public/models/NOTICE.md`：遊戲素材的來源說明。
- `renders/commanders-v13/index.html`：內嵌修正前後的實際 Babylon.js 截圖，不依賴相鄰圖片檔。

正常完整重建仍使用 `npm run models`。本次先在 `.tmp/commanders-v13/` 產生資產，通過檢查後只移入兩位武將的模型／貼圖；小兵 GLB 保持原檔。

## 驗證範圍

`tests/commander-grip.test.mjs` 直接取樣 GLB 匯出的骨骼動畫及 inverse bind matrices，在非關鍵幀時刻驗證左右手握持中心與武器軸向；兩位武將共 2,352 個取樣點，以模型座標驗證，允許位置誤差小於 4 mm、軸向 dot product 大於 0.999。另檢查家康刀柄長度、動作時長和手臂回到起始方向。這不是完整皮膚與武器表面的碰撞檢測。

既有素材測試檢查單一材質、貼圖雜湊、UV、18 骨架、權重、動畫與高模烘焙資訊。兩位武將各自的預算為 50,000 三角面、4.5 MB GLB；小兵預算不變。

尚待美術項目：拇指根部、皮革壓褶、甲冑細部雕刻、完整手指開合動畫。桌機 Chromium 的手機尺寸檢查不等同實機手機效能測試。
